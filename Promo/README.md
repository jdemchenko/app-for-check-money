# CheckMoney — Promo Deck

Fullscreen promotional slides for **CheckMoney** (Ivan Demchenko): voice-first personal finance for iPhone.

Russian primary copy · short English subtitles · keyboard / arrow / swipe navigation · `?clean=1` for screenshot export.

## Run

```bash
cd Promo
npm install
npm run dev
```

Open [http://127.0.0.1:47321](http://127.0.0.1:47321).

- **← → / Space / PageUp·PageDown** — navigate
- **Home / End** — first / last
- **`?slide=3`** — deep-link to a slide (1-based)
- **`?clean=1`** — hide chrome for screenshots

## Build

```bash
npm run build
npm run preview
```
